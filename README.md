# Banner & Header Generation Agent

סוכן Claude Code שמייצר באנר צד (310×600) וכותרת (1366×200) ללקוח חדש על פלטפורמת EzGo, באמצעות Canva MCP.

## מה הסוכן עושה

1. **מחקר מותג** — שולף מהאתר/פייסבוק/אינסטגרם של הלקוח: שם, צבעים, לוגו, פונטים, טון, שפה.
2. **לוגו** — משתמש בלוגו הקיים אם איכותו מספקת, או מייצר 3 וריאציות חדשות בקאנבה.
3. **קופי** — מייצר 3 כותרות בסגנונות שונים (ישיר / רגשי / הרפתקני) ומבקש לבחור.
4. **עיצוב בקאנבה** — מייצר 3 וריאציות לכל אחד (באנר + כותרת), משלב את הלוגו, ומחזיר קישור עיצוב מוכן.

בכל שלב יש נקודת אישור — הסוכן עוצר ומחכה לבחירה לפני שממשיך.

## איך מפעילים

ב-Claude Code בתיקיית הפרויקט:

```
/banner-create https://example.com
```

הסוכן יעבור על 4 השלבים, יעצור בכל נקודת אישור, ובסוף יחזיר שני קישורי קאנבה. ההורדה ל-PNG מתבצעת ידנית בקאנבה: **Share → Download → PNG**.

## דרישות סביבה

- Claude Code עם MCP של Canva מוגדר ופעיל.
- Python 3 זמין (לעיבוד תמונות וניתוח HTML). הסוכן מתקין את התלויות בעצמו בתחילת כל סשן.

## תיעוד מלא

- `docs/PRD.md` — מפרט המוצר המלא (גרסה 2.0).
- `CLAUDE.md` — הוראות התפעול לסוכן.
- `prompts/` — תבניות פרומפט לקאנבה (באנר / כותרת / לוגו).
- `docs/schemas/` — סכימות JSON של קבצי המצב.
